# Rights status

**State: private technical work. Public source and binary redistribution are not approved.**

- The owner authorized private porting of Super Mario Galaxy from a personal legal backup.
- The backup lives in the workspace as a WBFS file and is gitignored. It is never committed, uploaded, or packed into a redistributable VPK.
- Downstream users must supply their own `RMGE01` revision 0 image. Scripts generate a VPK and a separate game-data folder on the builder's machine.
- ModernGekko, RecompCore/Dolphin, and DolRecomp are GPL-3.0-or-later. GalaxyVita is GPL-3.0-or-later. A public source release, if ever authorized, must include corresponding source and notices.
- Petari is a read-only semantic reference (RMGK01). It is not the executable path and is not vendored until explicitly pinned as a research submodule.
- Nintendo's game, names, and assets are not ours to ship. Original LiveArea art must not use Nintendo graphics.
